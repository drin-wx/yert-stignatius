# Y.E.R.T. Website

Youth Environment & Emergency Response Team (Y.E.R.T.)
St. Ignatius — Cabuyao Campus

## Files
- index.html — home / membership
- officers.html — officers
- environment.html — environment division
- rescue.html — rescue team
- about.html — about + legal notices
- contact.html — contact form
- donate.html — support / donation page
- style.css — complete responsive styling
- script.js — mobile menu, scroll reveal, back-to-top, demo forms
- assets/yert-logo.png — supplied official logo

## Notes
- The site uses Montserrat + Outfit from Google Fonts and Font Awesome icons from CDN.
- The forms are front-end demo forms only; connect them to an approved backend before production.
- Replace placeholder officer names and contact/donation details with official information.
- "Java" in a website normally means JavaScript; this project uses `script.js` for browser interactions.
- The site is responsive for mobile, tablet, laptop, and desktop.
